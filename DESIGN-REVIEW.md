# HAWA v4 — Multi-agent design review (round 2)

Four specialist passes over v3, each hunting for "AI-template" tells and pushing toward a handmade, human feel.

## Agent A — Brand & Visual Designer
1. Everything is perfectly aligned and evenly spaced → looks generated. Add deliberate, tiny rotations and uneven rhythm.
2. Borders are all identical 2px → introduce wobbly "hand-drawn" border radii.
3. Photos sit in perfect rectangles → make them polaroids with tape and handwritten captions.
4. Flat color blocks → add paper grain/noise overlay so it feels printed, not rendered.
5. Headings need a hand-drawn underline squiggle, not a plain color span.
6. Section dividers are straight lines → torn-paper / zigzag clip-path edges.
7. Add doodles: hand-drawn arrows pointing at CTAs, stars, squiggles (inline SVG).
8. Buttons all identical → vary shadow direction per position, add "pressed" active state (already there, keep).
9. Add a handwritten font (Caveat) for annotations, prices-asides, captions.
10. Alternate light "paper" sections with dark ones so the page breathes like a printed menu.

## Agent B — UX Critic
11. Cart drawer is fine but the checkout feels like a form, not a ritual → add step personality and playful placeholders.
12. Track page map is abstract → label it like a real dispatch note, add rider card with name + handwritten ETA.
13. Menu grid is uniform → keep, but add one "chef's note" handwritten card inside the grid.
14. Search placeholder is plain → make it chatty ("try 'biryani'…").
15. Empty states are plain → hand-drawn empty-cart doodle + Caveat text.
16. Toast is a plain pill → make it look like a taped sticky note.
17. Add "how ordering works" 3 steps on the landing so first-time users aren't lost.
18. Nav active state is fine; add a hand-drawn underline instead of a box on desktop.
19. Focus rings should feel intentional (thick acid outline already; keep, add offset wobble).
20. Add keyboard hint on cart bar (Enter) — already; make cart bar wobble slightly to draw the eye.
