# Charm — TypeUI Design Skill (installed from https://www.typeui.sh/design-skills/charm)

Polished, production-ready design system for AI coding assistants. Warm light surfaces,
coral actions, cream accent bands, pill controls, softly rounded panels — approachable
and confident, not cold or overly corporate.

## Design Tokens

### Color Palette
| Token | Value | Purpose |
| --- | --- | --- |
| Section Surface | `#F7F7F5` | Warm, matte content canvas |
| Panel | `#FBFAF9` | Cards and raised content surfaces |
| Accent Band | `#F1F2EA` | Hero and footer backgrounds |
| Brand | `#E4544B` | Primary actions and brand emphasis |
| Brand Text | `#C9443A` | Accessible links and text accents |
| Heading | `#1C1917` | High-emphasis warm stone ink |
| Body | `#57534E` | Primary reading text |
| Muted Body | `#79716B` | Supporting copy and metadata |
| Border | `#E7E6E5` | Subtle component boundaries |

Status colors are reserved for real success/danger/warning states, not decoration.

### Typography
- **Inter** — body text, navigation, controls, button labels
- **Circular** (display slot) with **DM Sans** as free fallback — bold, tight tracking headings
- **Fragment Mono** — uppercase labels, eyebrows, ticker text, code details
- Hierarchy: compact product UI up to 72px marketing display headings

### Shape and Spacing
- Pill-shaped buttons, inputs, alerts
- Cards/widgets/modals/tables/drawers: **24px** corners; menus **12px**; textareas panel-shaped; checkboxes 4px
- 4px spacing token scale; centered containers up to **1280px**; generous section rhythm

### Surface and Depth
- Warm tone changes + hairline borders + spacing instead of heavy shadows
- Subtle control lift on buttons/inputs; medium floating shadow for menus/popovers
- Optional coral glow reserved for genuinely emphasized brand elements
- Hero may use one subtle line-pattern; rest of UI flat and untextured

### Component Language
- Primary actions: coral gradient, white label, restrained layered shadow, accessible hover/focus
- Resting cards: light, quietly bordered
- Semantic tokens, responsive behavior, focus visibility, contrast rules everywhere

## Best For
Polished SaaS products, welcoming marketing sites, modern storefronts, customer
dashboards, onboarding flows, productivity tools, warm/trustworthy service brands.
